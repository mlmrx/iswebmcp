# isWebMCP Claude plugin

Portable Claude Code plugin for the isWebMCP remote MCP service.

## Install locally

From a Claude Code session, add this directory as a development plugin or install it from a plugin marketplace that contains this folder. The plugin registers `https://iswebmcp.com/mcp` and adds the `audit-webmcp` skill.

Try: `Audit https://example.com for WebMCP readiness and state the evidence limits.`

The service retrieves the public URL you request. Do not submit private, authenticated, local-network, or secret-bearing URLs.
