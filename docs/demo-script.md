# Demo script — 160 seconds

Target length: 2:40 with narration and audio. Use one clean browser window, 125–150% cursor visibility, and no personal tabs or notifications.

## 0–13 seconds — The problem

**Screen:** Hero, Quick Scan, and “Presence is not proof.”

**Narration:** “A site can mention WebMCP—or even register tools—and still be unusable by an agent. Presence is not readiness, and readiness is not successful, safe action. isWebMCP turns that gap into evidence.”

## 13–35 seconds — Detect without pretending

**Screen:** Submit a prepared public URL and open the report.

**Narration:** “Quick Scan safely reads public source without executing the target’s JavaScript. It maps semantic controls, accessible names, actions, transport, and source hints. Every conclusion shows its provenance, while runtime remains explicitly unverified.”

Pause on the three evidence cards.

**Narration:** “Source Actionability describes only captured HTML. Contract Lint starts only with sanitized imported definitions. Runtime Readiness requires observed trials. Unknown evidence never becomes a made-up zero—or a made-up success.”

## 35–53 seconds — Audit the contract

**Screen:** Import the bundled sanitized manifest example, then reveal the derived report and one finding.

**Narration:** “A developer can import a sanitized tool inventory. isWebMCP bounds and summarizes the schema, rejects credential-like or dangerous structure, and creates an immutable derived report. Imported evidence is always labeled not independently verified.”

## 53–72 seconds — Publish collection truth

**Screen:** Readiness Index summary, then the collection-health panel and methodology note.

**Narration:** “The frozen WRI v1 crawl scheduled one hundred thousand Tranco ranks. An integrity audit found thirty-four thousand six hundred twenty scanner-infrastructure failures, so only sixty-five thousand three hundred eighty rows are valid collection outcomes. The public status is audited partial, and its heuristic is explicitly uncalibrated.”

## 72–96 seconds — Teach the shared task

**Screen:** Proof Lab in baseline mode. Play the illustrative replay and keep its authored-replay label and withheld Lift state visible.

**Narration:** “The lab uses one synthetic catalog, one visible interface, one business-logic path, and seven observable success criteria. This replay is an authored teaching timeline. No agent trial occurred, so isWebMCP does not turn it into a numeric Lift score.”

## 96–127 seconds — Observe a real runtime trial

**Screen:** In a supported top-level browser/agent environment, start a new interactive WebMCP run. Show the real search, compare, cart, and finish tool trace while visible state updates.

**Narration:** “Now this is observed runtime evidence. Structured search filters the visible catalog. Compare uses stable IDs. Cart updates the same UI state. Finish verifies every postcondition, and the lab never performs checkout. We retain the browser, model, trace, and result instead of generalizing from a scripted animation.”

## 127–148 seconds — Compare only qualifying evidence

**Screen:** Compare the completed interactive WebMCP run with a separately recorded interactive UI-only run of the same fixture. Show raw metrics and the evidence-mode labels.

**Narration:** “Only paired interactive runs of the same task and starting state can produce WebMCP Lift. The report publishes raw actions, time, retries, intervention, verification, each normalized component, and the formula. If either side is authored replay—or the pair is mismatched—the number is withheld.”

## 148–160 seconds — Show the design space and close

**Screen:** Sweep across the 24-pattern gallery, open one security scenario, then return to the hero.

**Narration:** “Twenty-four explorable patterns show how value, contracts, security, and reliability fit together. isWebMCP turns WebMCP from a presence check into an evidence discipline. Map it. Contract it. Prove it.”

## Capture notes

- Keep the deployment URL visible once.
- Show “source-only,” “not independently verified,” “authored replay,” “audited partial,” and “uncalibrated” labels long enough to read.
- Use a supported browser/model and preserve the real tool trace. Never animate a fake call or pair authored replay with an interactive run.
- Record at 1080p or higher, normalize narration audio, add captions, and verify the final exported video is under three minutes.
