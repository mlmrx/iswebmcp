- [Standalone blank pilot worksheet](https://iswebmcp.com/enterprise/pilot-worksheet).

Company facts are separated from our proposals in typed data under `lib/enterprise`. Source IDs link each factual assertion to an official document; unknown publication dates remain unknown. Scoring is a transparent editorial prioritization, not measured adoption, an endorsement, or a company-quality ranking. No vendor application has been scanned or integration tested for these briefs.

## Product boundary

The useful present offer is one approved public-page check, developer-reviewed starter guidance, saved source evidence, and a repeat check in an existing release process. The Node CLI calls the hosted scanner; only saved-report comparison is local. The current recipes cover a search tool and accessible controls. Developers apply and deploy their own changes.

Private/authenticated execution, an independent browser-task runner, tenant history, SSO/RBAC, configurable hosted retention and an enterprise SLA are separate development work. No enterprise infrastructure was provisioned here. Browser WebMCP remains experimental and distinct from ordinary remote MCP.

The main homepage remains the developer utility. This track is discoverable under Resources and in the footer; it adds no primary navigation category or company-logo wall. The earlier smaller-tool pipeline under `docs/partners` remains a separate track and has not been overwritten.

## Recommended next decisions

1. Rehearse the playbook on our own non-sensitive fixture without suggesting a company participated.
2. Prioritize Vercel for a narrow public release-workflow design pilot, and Adobe or Microsoft for an owner-approved reference-template enterprise pilot.
3. Treat Cloudflare's experimental browser lab and a Browserbase evidence adapter as separate research phases, not ready-made production integrations.
4. Before any outreach, select the sender, approve the exact message, recheck the public route and obtain the recipient's agreement to a bounded pilot. Nothing was sent or submitted for this shortlist.
5. Collect real evidence and permission before publishing named-company results, quotes or logos. These pages are prospective scenarios, not completed customer case studies.

The source repository is currently private; public users should receive the website downloads, not instructions that require repository access. No access controls, account registrations, paid services or hosting migrations are part of this delivery. The frozen partial WRI v1 artifact is untouched and is not used as enterprise or partner evidence.
