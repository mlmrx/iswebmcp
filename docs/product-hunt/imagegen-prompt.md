# Image-generation prompt

The launch hero background was created with the built-in image generation model using this exact prompt:

```text
Use case: ads-marketing
Asset type: Product Hunt launch campaign background
Primary request: Create an abstract evidence map for a developer tool that turns chaotic web interfaces into structured, verifiable agent contracts.
Scene/backdrop: warm off-white editorial paper field with a precise black technical grid; tangled interface fragments and ambiguous nodes on the left resolve into clean contract cards, connected checkpoints, and verified outcomes on the right.
Style/medium: premium flat editorial-tech illustration, modern Swiss technical poster, subtle paper grain, crisp vector-like geometry, restrained and sophisticated.
Composition/framing: wide 16:9 composition with generous negative space across the upper-left and center for later deterministic typography; visual movement left-to-right; a bold electric-chartreuse verification path as the focal element; small cobalt-blue accents only.
Lighting/mood: clear, rigorous, confident, evidence-driven.
Palette: warm ivory #F6F2E8, near-black #151816, chartreuse #A7E000, cobalt #3157D5, muted gray #69706B.
Constraints: no words, no letters, no numbers, no logos, no product UI screenshots, no people, no 3D, no gradients, no watermarks, no browser brand marks. Text will be added later outside the image model.
```

The generated source is `public/product-hunt/source/evidence-map-background.png`. Exact typography, product screenshots, data values, and final crops are produced by `scripts/product-hunt/render-assets.ts`.
