# Product Hunt demo video — 60-second cut

Use one clean browser window at 1080p or higher. Keep the deployment URL visible once. Add burned-in captions and export a public or unlisted YouTube video.

## Title

isWebMCP in 60 seconds — prove your web app is agent-ready

## Thumbnail line

Source hint ≠ runtime proof

## Shot list and narration

### 0–6 seconds — The claim

**Screen:** Home hero and Quick Scan.

**Narration:** “Agent-ready should describe an observed result—not a badge detected in source.”

### 6–17 seconds — Map it

**Screen:** Load the bundled sample report. Pause on evidence provenance and the runtime-unknown state.

**Narration:** “isWebMCP maps candidate actions from bounded public source, then keeps source clues separate from runtime evidence.”

### 17–27 seconds — Contract it

**Screen:** Contract Workbench with a sanitized example; reveal one precise finding.

**Narration:** “Audit narrow tool contracts for clear inputs, safety boundaries, and verifiable outcomes.”

### 27–43 seconds — Prove it

**Screen:** Proof Lab. Show the same task and starting state on both paths. If a real supported runtime is available, show its recorded trace. Otherwise keep the authored-replay label visible and do not show numeric lift.

**Narration:** “Run the same controlled task through the UI and WebMCP paths. Lift appears only when both interactive trials qualify.”

### 43–52 seconds — Explore the design space

**Screen:** Fast sweep of `/demos`, opening one security pattern.

**Narration:** “Twenty-four interactive patterns make value, contracts, security, reliability, and human confirmation visible.”

### 52–60 seconds — Close

**Screen:** Return to hero, then logo lockup and URL.

**Narration:** “No invented runtime proof. No made-up certainty. Map it. Contract it. Prove it—at iswebmcp.com.”

## On-screen disclosure slate

Use this small final caption for at least two seconds:

> WebMCP is experimental Community Group work. isWebMCP is independent. Evidence scope and limitations are shown in-product.

## YouTube description

isWebMCP is a free evidence lab for agent-ready web apps. Scan bounded public source, lint sanitized WebMCP contracts, explore 24 interactive patterns, and compare UI and tool paths on the same controlled task.

Try it: https://iswebmcp.com

Methodology: https://iswebmcp.com/methodology

WebMCP is experimental Community Group work, not a W3C Standard. isWebMCP is independent and is not an official OpenAI, Google, Microsoft, Chrome, or W3C product.

## Capture checklist

- Close personal tabs, notifications, password managers, and account menus.
- Use prepared public sample data; never record credentials or private URLs.
- Do not animate fake tool calls.
- Keep `source-only`, `not independently verified`, `authored replay`, `audited partial`, and `uncalibrated` labels legible when shown.
- Use a real trace only in a supported environment, with browser/model context retained.
- Normalize narration, remove dead air, add captions, and verify the exported link while signed out.
- Verify the video is not marked private.
