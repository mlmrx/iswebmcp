## 50-word description

isWebMCP helps web teams move from agent-readiness claims to inspectable evidence. It combines a bounded public-source scan, sanitized contract lint, 24 interactive before-and-after patterns, and a matched-path Proof Lab. Source clues, imported schemas, runtime results, and measured lift stay separate, so missing evidence remains visibly unknown.

## 100-word description

isWebMCP is an independent evidence laboratory for agent-ready web applications. Developers can map candidate actions from bounded public source, lint sanitized WebMCP tool inventories, explore 24 interactive patterns across value, contracts, security, and reliability, and run a controlled synthetic task through visible-UI and tool-based paths. The product preserves provenance across source observations, imported definitions, observed runtime trials, and matched lift calculations. It also publishes WRI v1 as a frozen, uncalibrated, audited-partial dataset after quarantining scanner-infrastructure failures. WebMCP is experimental Community Group work, and isWebMCP does not claim official certification or standards authority.

## Boilerplate

Prove it.” The platform includes Quick Scan, Contract Workbench, Proof Lab, 24 synthetic interaction patterns, an audited-partial readiness dataset, a learning center, FAQ, Pulse updates, and portable evidence exports. Learn more at https://iswebmcp.com.
